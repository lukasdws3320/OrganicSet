# Comece aqui

**Editores (Windows):** siga o guia passo a passo: https://claude.ai/artifact/6XK2adJ5FNHKcbLoFHTuge
Para atualizar depois: dois cliques em `Atualizar OrganicSet (Windows).bat`.

1. Coloque esta pasta `OrganicSet` em Documentos. Não renomeie as pastas de dentro.
2. Dê dois cliques em `instalar.command` (se o Mac bloquear: botão direito → Abrir → Abrir). Ele instala tudo; pode pedir a senha do Mac uma vez.
3. Abra esta pasta no Claude Code (ou no Codex) e escreva: **configurar**. O agente faz as perguntas e liga a sua conta do Flow.
4. Para usar o Reference Hub, dê dois cliques em `Abrir Hub.command`.
5. Para ver rápido seus experts e os prompts, abra `Reference Hub.html`.

**No Windows:** use `instalar (Windows).bat` no lugar do passo 2 e `Abrir Hub (Windows).bat` no lugar do passo 4. Depois de instalar, feche e abra o VS Code.

Depois é só conversar: "cria meu avatar", "replica esse reel: <link>", "faz as legendas", "o que eu posto hoje?".
